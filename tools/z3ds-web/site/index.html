Z3DS Compressor

Compresses 3DS games into the formats azahar plays directly: .zcci, .zcxi, .z3dsx and .zcia. It all runs in this browser: your files are never uploaded.

    Playing the compressed files

    On a Vita, copy them to ux0:data/azahar/roms/: azahar lists .zcci, .zcxi and .z3dsx files there. On a PC or Android, open them in azahar like any ROM, and install a .zcia the way you install a CIA.

    The format

    A Z3DS file keeps the ROM in independent zstd frames of 256 KiB (32 MiB for a CIA) followed by a seek table, so azahar decompresses only the parts a game reads. At level 3 this page writes the same compressed bytes as azahar's own compressor.

    Your browser

    Chrome and Edge save straight to disk. Firefox and Safari build the file in the browser's storage first, then download it, so they need room for it twice for a moment.
